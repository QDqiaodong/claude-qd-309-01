# 洗车房 · 工位与洗车单

洗车房的日常台账：**工位**、**洗车单**、**耗材**、**会员卡**。

业务重点：
- **状态用枚举写**（`enums/WashState` 等），状态机规则也放在枚举上（`canMoveTo`），
  洗车单只能「待洗 → 清洗中 → 已完成」一步步走，跳步和回退都会被拦；
- **回炉台**（`enums/ReworkState`）：只能挂在已完成单上，回炉自己按
  「待回炉 → 回炉中 → 已验收」走，验收不过只能「已作废」；挂回炉先认原工位，认不上（停用/满位）才改派到空闲工位；
- **工位占用统一口径**（`BayOccupancyService`）：没洗完的洗车单 + 回炉中的车一起算占座，
  开新单、挂回炉、改派、工位列表都认这一份；
- **耗材出库**封装在实体里（`Supply.consume`），不够就不给用，见底自动标成已用完；
  回炉作废退料走 `Supply.restore`，数量加回、状态按现库存归位；
- **回炉二次领料**（`rework_supply`）：挂回炉必须同时写清再拿的泡沫、毛巾各几件，
  料先从货架扣到账上才允许挂；货架不够整笔领料失败、回炉也挂不上；
- **会员卡扣费**（`MemberCard.pay`）：停卡或余额不足都扣不动。
  二次领料只动耗材库存，会员卡余额、洗车单原价一律不参与。
- **卡账钉单**（`card_flow`）：刷卡必须钉在这一张洗车单上，金额跟单上写明的价一致才许动余额；
  每动一次余额落一行卡流水（钉卡、钉单、钉这笔之后的余额），单上也记下是哪一笔扣的，
  晚班对账从卡流水找单、从单找流水，两头对得上。

## 技术栈

- 后端：Spring Boot 3.3 / Java 17、Spring Data JPA（**状态一律用枚举 + `@Enumerated(EnumType.STRING)`**）、
  MySQL 8、Redis 7
- 前端：Vue 3（Options API，页面逻辑主要靠 computed 串起来）+ Element Plus + Vite
- 一键起：`./start.sh`

## 业务模块

1. **工位**（`bay`）—— 编号名称、同时容纳、空闲/占用/停用；占用数 = 洗车单 + 回炉中
2. **洗车单**（`wash_order`）—— 单号车牌、工位、服务与金额、三态流转；回炉未结时钉在已完成；
   整笔撤单走「已撤销」终态，刷过卡的会连同卡账一起了
3. **回炉**（`rework`）—— 挂在已完成单上的返工，待回炉 → 回炉中 → 已验收（客人仍不满意则「已作废」），工位先认后改派；二次领料账在 `rework_supply`
4. **耗材**（`supply`）—— 编号名称单位、库存与预警线、正常/不足/已用完
5. **会员卡**（`member_card`）—— 卡号持卡人、余额与等级、正常与停卡；动账流水在 `card_flow`

### 回炉台规则

- 回炉只能挂在**已完成**的洗车单上；同一张原单只要还有未验收回炉，不得再挂第二张。
- 挂上必须**先认原单工位**；原工位停用或被别的车占满，才允许改派到别的空闲工位。
  原工位还空着时嫌麻烦随便找空位会被拦。
- 回炉中的车**算工位占用**：工位满了接不了新回炉，也开不了新单；停用、满位都当场报清原因。
- 回炉中工位被停用：单子不拆，只能改派到别的空闲工位；没有空位则整次改派失败，状态停在回炉中，
  也不能在停用工位上直接验收（不会偷偷变已验收）。
- 挂着未验收回炉的原单继续停在已完成，列表和详情都有「回炉未结」标，且不能退回待洗/清洗中。
- 历史上已完成、从没回炉记录的单子照样可以挂回炉，不会被灰掉。

### 回炉二次领料（仓管口径）

- 挂回炉的**同时必须写清这次再拿的泡沫、毛巾各几件**（名称带「泡沫」「毛巾」的耗材各一行），
  不写、写 0、写成别的耗材都不给挂。
- **先扣料、后挂单**：两行库存先各自验一遍，任一样货架现数不够，整笔领料失败、一件都不动，回炉也挂不上；
  不许先挂回炉回头再补泡沫。
- 回炉做到一半客人仍不满意、这条回炉**没有验收通过**（点「验收不过·作废退料」，回炉变「已作废」）：
  二次领料**整笔退回货架**，库存加回、状态按现库存重新归位，领料行标「已退架」。
- **验收通过**：二次领的泡沫、毛巾算正式用掉，库存**不再加回**。
- 二次领料只动耗材库存，**会员卡余额、洗车单原价都不许拿来顶这次领料**。

### 卡账规则（店长口径）

- 刷卡**必须钉在这一张洗车单上**：接口只认「单 + 卡」，单号没钉上（单不存在）一分钱不许动，
  不许先刷卡再补单号——先扣后补会留下对不上的流水。
- **金额跟这单写明的价一致才许动余额**：收银不用填金额，按单上的价扣；
  填了就必须跟单价一致，对不上当场拦，卡上一分不动。
- 这单**已经记过一笔成功扣款，再刷必须挡下**：单上钉着那笔流水号，重复刷卡卡上数字不再少。
- **停卡、余额不够，整笔都动不了**，不许先扣一半（`MemberCard.pay` 原子扣）。
- **整笔撤单**（单 →「已撤销」终态）：已扣的那笔**原数退回原来那张卡**（停卡也照退，退款不是扣款），
  卡上余额按退回后的数归位；没刷过卡的单撤掉不动卡。撤过的单不许再刷、再撤、再改。
- 已刷过卡的单**金额钉死在流水上**，不许再改价；要改先整笔撤掉退款再重开。
- 每动一次余额落一行 `card_flow`（钉卡、钉单、钉这笔之后的卡余额，退款行指回原扣款），
  单上也记下是哪一笔扣的（`pay_flow_id`）；晚班对账从卡流水找单、从单找流水，两头对得上。
